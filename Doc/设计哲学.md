## 快速失败原则

不要为报错和可能报错的点进行软处理（比如数组传参的越界处理），尽可能第一时间暴露错误的调用参数和错误的逻辑，便于在开发阶段第一时间发现并追踪发生原因

---

## 三相事件

每个行为拆为三个相位，共用同一个上下文实例：

```text
BeforeXxx(context)     询问：本次行为是否发生
  └ 可写 cancelled，置 true 则 return，后续相位都不发布

XxxResult(context)     询问：本次行为是什么样
  └ 可写上下文的数值与参数

AfterXxx(context)      通知：已按 context 执行完毕
  └ 只读
```

| 相位 | 权限 | 用途 |
| --- | --- | --- |
| Before | 只读全部；可写 `cancelled` | 条件门控、禁止类效果 |
| Result | 可写上下文的数值与参数 | 一次性修饰、方向翻转、伤害调整 |
| After | 全只读 | 消耗次数、连锁、表现广播 |

**取消只属于 Before。** 这是人为约定，不做编译期强制。语义是"本次行为不发生"——直接 `return`。

**After 的时机决定它能读到什么。** 若某个后果需要被影响，它必须晚于"决定后果"、早于"执行后果"；若需要保证清理，则需要一个必定发布的末段事件（参考 `AfterJumpEvent` 与 `LandEvent` 的分工）。

## 修饰集 vs 行为上下文

| | 修饰集 `ModifierSet` | 行为上下文 |
| --- | --- | --- |
| 语义 | 实体固有属性 | 本次行为的参数与事件量 |
| 生命周期 | 与实体同生共死 | 单次行为，用完即弃 |
| 谁写 | 持久型 Effect 的 `apply` | Result 相位的订阅者 |
| 扩展频率 | 高（随系统拓展） | 低（行为基本固定） |
| 结构 | 枚举 + 字典 | 具名字段 |

字典是为"未知的将来"付的钱：修饰集面对未知（会一直长），上下文面对已知（攻击无非伤害/暴击），**所以两者结构不同是对的**。

**统一点在值类型**——数值都用 `ModifiableValue`，操作词表一致（`AddAdditive` / `AddMultiplier` / `FinalValue`）。

### 上下文字段规则

只允许两类：

| 类别 | 类型 | 例子 |
| --- | --- | --- |
| 行为参数 | `bool` / `GameObject` / `int` | `toRightWall`、`victim`、`slotIndex` |
| 随事件产生的量 | `ModifiableValue` | `damage` |

**固有属性一律不复制为字段**，一律经 `context.attributes.Final(Key.X)` 读取。判定依据是"这个数据属于实体，还是属于这一次行为"：

- 滞空时长、移动速度、冷却时长 → 固有属性，进修饰集
- 本次伤害 → 随事件产生（受击方的伤害由攻击方传入），进上下文

## 判定顺序

**各相位只在"自己的时刻"读取属性值，判定一旦做出不再复核。**

- **属性不回写**：Result 相位的修改只作用于上下文自身字段。`GetModifierSet()` 每次调用都会 `ClearModify()` 重算，写入修饰集的内容下一次会被清掉，所以"Result 改属性导致 Before 判定变化"在架构上不可能发生。
- **不隐式重试**：要实现"改了之后重新判定"，必须显式再发一次 Before 事件。
- **相位内的顺序相关性**取决于写什么：

| 写什么 | 顺序相关 | 原因 |
| --- | :---: | --- |
| `AddAdditive` / `AddMultiplier` | 否 | 加区/乘区分桶聚合，与注册顺序无关 |
| `bool` 直接赋值 | 是 | 赋值语义 |

数值部分顺序无关，是把 `ModifiableValue` 用作上下文数值类型的直接收益。

---

## 数据只有浮点一种

**可修饰数据只有浮点。** `ModifiableValue` 的存在意义就是加区与乘区两套运算，那是浮点特有的语义，int / bool 套不进去。

- int 在读取点强转：`(int)Final(Key.X)`
- bool 只作为行为参数存在，不参与修饰
- 因此不需要标签联合体、不需要 `object` 装箱、不需要类型校验

**冷却等"剩余量"存比例而非绝对值。** 比例是上限的不变量，上限被修饰时无需任何同步动作，于是观察者机制整体移除：`ModifiableValue` 退化为纯公式，不再有任何回调。
